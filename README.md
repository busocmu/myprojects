# My Projects

This repository contains a collection of academic and personal projects focused on **cyber security, networking, cryptography, and digital forensics**. The projects demonstrate both theoretical knowledge and practical application using industry-relevant tools and techniques.

---

## 📁 Repository Contents

### 📄 Intrusion_detection_system_report.docx
A comprehensive report on the design and evaluation of an **Intrusion Detection System (IDS)**.  
The report covers:
- Network security concepts and IDS architectures  
- Detection of malicious network traffic, including potential DDoS attacks  
- The application of machine learning and deep learning techniques to improve detection accuracy  

---

### 🐍 caesar submit.py
A Python script implementing the **Caesar cipher** encryption technique.  
This script demonstrates:
- Fundamental cryptographic principles  
- Encryption and decryption using character shifting  
- Core Python programming skills  

---

### 📄 forensics analysis report.docx
A digital forensics investigation report documenting the **analysis of a system or virtual machine**.  
Key areas include:
- Forensic methodology and evidence handling  
- Use of forensic tools for file and system analysis  
- Identification and interpretation of digital artefacts  

---

### 🌐 network setup.pkt
A **Cisco Packet Tracer** network simulation file illustrating a complete network setup.  
The topology demonstrates:
- Network design using routers and switches  
- IP addressing and network connectivity  
- Fundamental networking and security concepts
